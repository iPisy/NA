# Compilation instructions 
Open your terminal at the root directory of the project at first. 
The project uses `makefile` to build. All available command are listed below.  
- `make build` Build all binary files of this project. Programs will lie in `bin/`. By the way, `build/` is the directory of files generated by `CMake`.
- `make run` Run all binary files to test the project. <!-- It relies on `run.sh` in `src/`. Modify it if needed and change `make runTest` part in makefile.-->
- `make report` Generate report(at least a report with doxygen) of this project. All report will lie in `report/` and will be opened by `makefile`.
- `make clean` Clean all generated files.

#### Compilation instructions *(for programmer)*
- `make buildInDubug`  Build all binary files, each of which can run with GDB. Programs will also lie in `lib/`.
- `make runTest` Run all binary files that test the class in `lib/`.
- `make simpleTest` Run code in `/test` to test a short code block.
