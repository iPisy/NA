\section*{B.}

I use \textbf{class Interpolator\_N} to interpolate with Newton formula.

Just set the uniformly spaced interpolation points across the definition domain,  
which can be generated by member function of \textbf{class Function} given the number of points, 
and do interpolation. 
Repeated it 4 times, I get 4 interpolation polynomial.

\begin{flalign*}
  & p_1(x) = 1 - 0.0384615x^2 \\
  & p_3(x) = 1 - 0.171088x^2 + 0.00530504x^4 \\
  & p_5(x) = 1 - 0.351364x^2 + 0.0335319x^4 - 0.000840633x^6 \\
  & p_7(x) = 1 - 0.528121x^2 + 0.0981875x^4 - 0.00658016x^6 + 0.000137445x^8 
\end{flalign*}

\section*{E.}

I use \textbf{class Interpolator\_N} to interpolate with Newton formula. 
I create 2 interpolators, initializing it with 2 samples and do interpolation. 
Then I get 2 interpolation polynomials, representing average weight curve for each sample.

Average weight polynomial for Sp1: 
$$p_6(x)=6.670000000000000 - 43.012663070144377*x + 16.285462366416521*x^2 - 2.115118256609702*x^3 + \ldots$$
Average weight polynomial for Sp2: 
$$p_6(x)=6.670000000000000 - 5.850179610199651*x + 2.982270554823253*x^2 - 0.424282510489892*x^3 + \ldots$$

For E(b), it apply interpolation polynomial on the point outside the 2 endpoints of the interpolation points, 
which I call interpolation domain below. 
On this occasion, $f^{n+1}(x)$ may have no definition or can be arbitrarily huge. 
Thus the remainder can be arbitrarily huge, the interpolation is now meaningless.

Actually, in the program, I have already restricted the definition domain of interpolation polynomial to be interpolation domain. 
Get the value out of the domain will \textbf{cause throwing exceptions}, which we can see when program E runs.

\section*{F.}

\textbf{\large Steps:}
\begin{enumerate}
  \item I use \textbf{class Curve} to store the curve. 
  It's independent variable is \textbf{t} and definition domain can be assigned by user. 
  \textbf{class Curve} consisting a vector of pointers to \textbf{class Function}, 
  which are all function of variable \textbf{t}. They are functions in direction of every basis vector.
  By the way, it have the same definition as it in book \cite{Curves}.

  \item \textbf{class Curve} can generate uniformly spaced(on t) points of given number across the definition domain
  using its member function. It is then given to \textbf{class CubicBezierSpline}, which have a 
  vector of pointer to \textbf{class CubicBezierCurve}. \textbf{class CubicBezierSpline} distribute the points to 
  \textbf{class CubicBezierCurve}. After that, \textbf{class CubicBezierCurve} can generate Cubic Bezier Curve, 
  using Algorithm 2.74 \cite{Algorithm2.74}. 
  I use $\frac{1}{3}-\frac{2}{5*\sqrt[4]{\text{number of curves on spline}}}$ instead of $\frac{1}{3}$ to optimize fitting performance.

  \item Then I print the generated spline to .tex files by a member function of \textbf{class CubicBezierSpline}. 
  It can be drawn by LaTex.
\end{enumerate}
  
Detailed explaination is presented in \textbf{index.html}.

That's because when $m$ goes large, some control points go closer to $x=\sqrt{3},-\sqrt{3},0$, 
where the value of the tangent vector at a certain direction converge to $\infty$. 
Thus generated control point $q_1$ and $q_2$ is not accurate, then the bezier curve can not converge to the original curve.
