I set the uniformly spaced interpolation points across the definition domain,  
which can be generated by a member function of \textbf{class Function} given the number of points. 
Then I do interpolation. 
Repeated it 4 times, I get 4 interpolation polynomials.

\begin{flalign*}
  & p_1(x) = 1 - 0.0384615x^2 \\

\section*{E.}

I use \textbf{class Interpolator\_N} to interpolate with Newton formula. 
I create 2 interpolators, initializing it with 2 samples and do interpolation. 
Then I get 2 interpolation polynomials, representing average weight curve for each sample.

Average weight polynomial for Sp1: 
$$p_6(x)=6.670000000000000 - 43.012663070144377*x + 16.285462366416521*x^2 - 2.115118256609702*x^3 + \ldots$$
Average weight polynomial for Sp2: 
$$p_6(x)=6.670000000000000 - 5.850179610199651*x + 2.982270554823253*x^2 - 0.424282510489892*x^3 + \ldots$$

For E(b), it apply interpolation polynomial on the point outside the 2 endpoints of the interpolation points, 
which I call interpolation domain below. 
On this occasion, $f^{n+1}(x)$ may have no definition or can be arbitrarily huge. 
Thus the remainder can be arbitrarily huge, the interpolation is now meaningless.

Actually, in the program, I have already restricted the definition domain of polynomial generated by interpolation to be interpolation domain. 
Get the value out of the domain will \textbf{cause throwing exceptions}, which we can see when program E runs.

\section*{F.}

\textbf{\large Steps:}
\begin{enumerate}
  \item I use \textbf{class Curve} to store the curve. 
  It's independent variable is \textbf{t} and definition domain can be assigned by user. 
  \textbf{class Curve} consisting a vector of pointers to \textbf{class Function}, 
  which are all function of variable \textbf{t} and they are functions in direction of every basis vector.
  By the way, it have the same definition as it in book \cite{Curves}.

  \item \textbf{class Curve} can generate an arbitrary given number of uniformly spaced(on t) points(with its tangent vector of arbitrary order) across the definition domain
  using its member function. It is then given to \textbf{class CubicBezierSpline}, which have a 
  vector of pointer to \textbf{class CubicBezierCurve}. \textbf{class CubicBezierSpline} distribute the generated points to 
  \textbf{class CubicBezierCurve}. After that, \textbf{class CubicBezierCurve} can generate Cubic Bezier Curve, 
  using Algorithm 2.74 \cite{Algorithm2.74}. 
  In algorithm, I use $\frac{1}{3}-\frac{2}{5*\sqrt[4]{\text{number of curves on spline}}}$ instead of $\frac{1}{3}$ to optimize fitting performance.

  \item Then I output the generated spline to .tex files by a member function of \textbf{class CubicBezierSpline}, 
  which use \textbf{class LatexOutputer} too.
\end{enumerate}
  
Detailed explaination of classes and member functions is presented in \textbf{index.html}.

Thus generated control point $q_1$ and $q_2$ is not accurate, then the bezier curve can not converge to the exact curve.
